# FactoryGuard 포트폴리오 실험 기록

## 해결하려는 문제

긴 산업현장 영상에서 작업자와 지게차가 화면상 가까워지는 구간을 자동으로 찾아 사람이 검토할 수 있게 한다.

## 구현 결정

- YOLO26s: person/forklift 커스텀 탐지 모델을 위한 시작점.
- ByteTrack: 객체 ID를 유지해 같은 쌍의 이벤트를 프레임 간 연결.
- 화면 대각선 정규화: 같은 화면을 동일 비율로 리사이즈해도 근접도 값 유지.
- 두 임계값과 최소 관측 시간: 경계에서의 흔들림과 짧은 오탐을 줄이기 위한 규칙.
- CSV와 MP4: DB/대시보드 없이 실행 결과를 바로 검토.

## 평가 방식

테스트 영상의 close approach 구간을 사람이 먼저 표시하고, 이벤트의 시간 중첩 기준을 정한 후 비교한다. 후보를 정답과 대응시켜 누락과 중복을 기록한다. validation 객체 탐지 성능과 이벤트 검토 성능을 혼합하지 않는다. 최종 테스트 영상으로 학습 모델이나 임계값을 반복 선택하지 않는다.

## 사례 기록

각 사례에 원본 구간, annotated clip, 적용 임계값, 결과, 원인을 함께 기록한다. 정상 예시뿐 아니라 가림, ID 변경, 다른 깊이의 객체가 가까워 보이는 실패 사례도 포함한다.

## 설명할 수 있는 한계

현재 규칙은 위치 근접만 관측한다. 실제 거리, 상대속도, 사고 확률을 계산하지 않는다. 원근과 ID switch를 해결하는 후속 작업은 별도 실험으로 다룬다.
